# Детекция событий у столика в ресторане (YOLOv8 + OpenCV)

Простой инструмент для анализа occupancy столика на видео с камеры наблюдения.  
Определяет три события: **Подход к столу**, **Стол занят**, **Стол освободился** и считает среднее время между уходом одного гостя и подходом следующего.

## Как запустить проект

### 1. Клонируйте репозиторий
gh repo clone Rifat172/Event-detection

cd Event-detection

### 2. Установите зависимости
pip install -r requirements.txt

### 3. Положите тестовое видео в папку со скриптом и выполните 
python main.py --video 'видео 2.mp4' (опционально: можно добавить флаг --headless True - для обработки видео без интерфейса)

При запуске появится окно "Select Table Zone" — выделите мышкой область столика (желательно с запасом вокруг) и нажмите ENTER.
Далее начнётся обработка видео.

### 4. Чтобы закрыть интефрейс необходимо на английской раскладке нажать 'q'

## Результаты:
output.mp4 — обработанное видео с визуализацией (цветная рамка столика + bounding box'ы людей)
table_stats.xlsx — таблица всех событий
Статистика выводится в консоль

## Описание выбранного видео и столика

Видео: видео 2.mp4
Столик: Выбран один чётко видимый столик с номером 15 (деревянный стол под лампой).
Зона выделена вручную через cv2.selectROI с запасом, чтобы ловить людей, стоящих рядом.

## Логика детекции событий

- **Модель детекции**: YOLOv8n (`yolov8n.pt`) — обнаруживает только людей (класс `person`)
- **Определение присутствия**: Пересечение bounding box человека с зоной столика (IoU > 0.15)
- **Гистерезис для стабильности**:
  - **Подход к столу**: ≥ 5 кадров присутствия
  - **Стол занят**: ≥ 15 кадров присутствия
  - **Стол освободился**: ≥ 75 кадров отсутствия (~3 секунды)
- **Фиксируемые события**:
  - `approach` — появление человека после пустоты
  - `occupied` — подтверждённое занятие стола
  - `vacated` — стол освободился
- **Время на кадре**: Распознаётся с помощью EasyOCR
- **Визуализация в выходном видео**:
  - Зелёный цвет — стол пустой
  - Красный цвет — стол занят
  - Серый цвет — идёт подход к столу
